# AetherDx

### AI-Powered Early Health Screening Through Nail Image Analysis

AetherDx is an AI-powered healthcare application that analyzes **nail images** to identify visual patterns associated with **liver disease and psoriasis**, providing preliminary screening insights through computer vision and explainable AI.

> **Disclaimer:** AetherDx is a screening and decision-support tool, not a replacement for professional medical diagnosis.

## Features

* AI-powered liver disease and psoriasis screening
* Nail image capture and analysis
* Computer vision and deep learning
* Explainable AI insights
* Confidence-based screening results
* Standardized image capture using a 3D-printed enclosure
* Designed for patients and healthcare professionals

## Technology Stack

**Frontend:** Flutter, Dart
**AI/ML:** Python, Computer Vision, Deep Learning, Explainable AI
**Backend:** REST API, Model Inference
**Infrastructure:** Cloud, Git, CI/CD
